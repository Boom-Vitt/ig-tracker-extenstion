## เกี่ยวกับโปรเจกต์นี้

**Instagram Follower Tracker** เป็นส่วนเสริม (Extension) สำหรับเบราว์เซอร์ Chrome, Edge หรือ Brave ที่ช่วยคุณ

- ติดตามรายชื่อ **ผู้ติดตาม (Followers)** และ **คนที่คุณติดตาม (Following)** ของบัญชี Instagram ของคุณเอง
- **แจ้งเตือน** เมื่อมีคนเลิกติดตาม (Unfollow)
- **ส่งออกข้อมูลเป็นไฟล์ CSV** (เปิดด้วย Excel หรือ Google Sheets ได้) เพื่อเก็บไว้ดูภายหลัง

> [!IMPORTANT]
> **ปลอดภัย 100%** — ไม่ต้องสมัครสมาชิก · ไม่ต้องกรอกรหัสผ่าน · ไม่มีเซิร์ฟเวอร์ภายนอก · ข้อมูลทั้งหมดเก็บอยู่ใน **เบราว์เซอร์ของคุณเอง** เท่านั้น

## การดาวน์โหลด

### ขั้นที่ 1 — ดาวน์โหลดไฟล์จาก GitHub

1. ไปที่หน้าโปรเจกต์บน GitHub
   ```
   https://github.com/Boom-Vitt/ig-tracker-extenstion
   ```
2. ในหน้ารายการไฟล์ ให้มองหาไฟล์ชื่อ
   ```
   insta-tracking-local.zip
   ```
3. **คลิกที่ชื่อไฟล์** เพื่อเข้าหน้าดูไฟล์
4. กดปุ่ม **`Download`** (ไอคอนรูป **ลูกศรชี้ลง** ↓ มุมขวาบนของไฟล์)
5. ไฟล์ ZIP จะถูกบันทึกลงในโฟลเดอร์ **Downloads** ของคุณ

> [!TIP]
> หากปุ่มดาวน์โหลดเปิดไฟล์ในแท็บใหม่แทนที่จะโหลด ให้ **คลิกขวา** ที่ปุ่ม แล้วเลือก **Save Link As…** เพื่อบันทึกไฟล์

### ขั้นที่ 2 — แตกไฟล์ ZIP

ระบบ | วิธีแตกไฟล์
--- | ---
**Windows** | คลิกขวาที่ไฟล์ `insta-tracking-local.zip` → เลือก **Extract All…** → กด **Extract**
**macOS** | **ดับเบิลคลิก** ที่ไฟล์ `insta-tracking-local.zip` ระบบจะแตกไฟล์ให้อัตโนมัติ

หลังแตกแล้วคุณจะได้ **โฟลเดอร์** ชื่อ `insta-tracking-local` ภายในมีไฟล์ประมาณนี้

```
insta-tracking-local/
├── manifest.json
├── background.js
├── content.js
├── sidepanel.html
├── sidepanel.css
├── sidepanel.js
├── README.md
└── icons/
```

> [!CAUTION]
> **อย่าลบโฟลเดอร์นี้** หลังจากติดตั้งแล้ว เพราะเบราว์เซอร์อ่านไฟล์จากโฟลเดอร์นี้โดยตรง แนะนำให้เก็บไว้ในที่ที่ไม่ลบ เช่น **Desktop** หรือ **Documents**

## วิธีใช้งาน

### ครั้งแรกที่ใช้

1. เปิดเว็บ [https://www.instagram.com](https://www.instagram.com) แล้ว **ล็อกอินบัญชี Instagram** ของคุณ
2. **คลิกไอคอน Extension** ที่ปักหมุดไว้ — แผง **Side Panel** จะเปิดทางขวามือ
3. กดปุ่ม **`Sync Now & Save Snapshot`** เพื่อบันทึก Snapshot แรก
   - กระบวนการนี้อาจใช้เวลาสักครู่ ขึ้นอยู่กับจำนวนผู้ติดตามของคุณ
   - ระบบจะหยุดพักเป็นระยะ เพื่อไม่ให้ Instagram บล็อก
4. เลือกช่วงเวลาในเมนู **`Auto-sync`** หากต้องการให้ระบบซิงค์อัตโนมัติ

### แท็บต่างๆ ในแผง Side Panel

| แท็บ | ความหมาย |
| --- | --- |
| **Unfollowers** | คนที่ **เคยติดตามคุณ** แต่ตอนนี้เลิกติดตามแล้ว |
| **New** | คนที่ **เพิ่งเริ่มติดตาม** คุณตั้งแต่ Snapshot ครั้งก่อน |
| **Ghosts** | คนที่คุณติดตามอยู่ แต่ **ไม่ติดตามกลับ** |
| **Fans** | คนที่ติดตามคุณ แต่ **คุณยังไม่ได้ติดตามกลับ** |
| **History** | ประวัติการ follow/unfollow ทั้งหมดในรูปแบบไทม์ไลน์ |

แต่ละแท็บมีปุ่ม **`Export CSV`** ของตัวเอง สามารถดาวน์โหลดเป็นไฟล์ตารางได้

## คำถามที่พบบ่อย

<details>
<summary><b>ปลอดภัยไหม? Extension นี้จะขโมยรหัสผ่านของฉันหรือเปล่า?</b></summary>

ไม่ต้องกังวลครับ Extension นี้:
- **ไม่เก็บรหัสผ่านของคุณ** เลย
- **ไม่ส่งข้อมูลออกไปข้างนอก** เซิร์ฟเวอร์ใดๆ
- ข้อมูลทั้งหมดเก็บอยู่ใน **เบราว์เซอร์ของคุณเอง** (`chrome.storage.local`)
- ใช้เซสชันล็อกอินที่คุณมีอยู่แล้ว เหมือนเปิดเว็บ Instagram ตามปกติ

โค้ดทั้งหมดเปิดเผยใน GitHub ตรวจสอบได้

</details>

<details>
<summary><b>ทำไมต้องเปิดโหมดนักพัฒนา (Developer mode)?</b></summary>

เพราะ Extension นี้ไม่ได้ลงทะเบียนใน Chrome Web Store (เก็บเป็นส่วนตัว) จึงต้องใช้วิธีติดตั้งแบบ **Load unpacked** ซึ่งต้องเปิดโหมดนักพัฒนาก่อน **ไม่ส่งผลเสียต่อความปลอดภัยของเบราว์เซอร์**

</details>

<details>
<summary><b>ฉันใช้ Safari หรือ Firefox ได้ไหม?</b></summary>

ตอนนี้ยัง **ไม่รองรับ** Safari และ Firefox — รองรับเฉพาะเบราว์เซอร์ตระกูล Chromium ได้แก่ **Chrome**, **Edge**, **Brave**, **Opera**, **Arc**

</details>

<details>
<summary><b>ถ้าลบโฟลเดอร์ <code>insta-tracking-local</code> Extension จะใช้ได้ไหม?</b></summary>

**ใช้ไม่ได้** เพราะ Chrome อ่านไฟล์จากโฟลเดอร์นั้นโดยตรง ถ้าลบโฟลเดอร์ Extension จะหายไปจากเบราว์เซอร์ ควรเก็บโฟลเดอร์ไว้ในที่ที่ไม่ได้ลบบ่อยๆ เช่น **Desktop** หรือ **Documents**

</details>

<details>
<summary><b>Auto-sync ไม่ทำงาน ทำยังไงดี?</b></summary>

Auto-sync จะทำงานได้ก็ต่อเมื่อ **มีแท็บ Instagram เปิดอยู่ในเบราว์เซอร์** ถ้าปิดทุกแท็บไว้ ระบบจะข้ามรอบนั้นและทำในรอบถัดไป

</details>

<details>
<summary><b>โดน Instagram บล็อกได้ไหม?</b></summary>

ระบบออกแบบให้ดึงข้อมูล **ช้าๆ** (~ 50 คนต่อวินาที พร้อมสุ่ม jitter) เพื่อลดความเสี่ยงโดน rate-limit หากเจอ rate-limit ระบบจะรอ (Exponential Backoff) และพยายามใหม่อัตโนมัติ

</details>

<details>
<summary><b>อัปเดต Extension ยังไง?</b></summary>

1. ดาวน์โหลดไฟล์ ZIP ตัวใหม่จาก GitHub
2. แตกไฟล์ทับโฟลเดอร์เดิม (หรือลบโฟลเดอร์เดิมก่อนแตกใหม่)
3. เปิดหน้า `chrome://extensions` แล้วกดปุ่ม **รีเฟรช** (ไอคอนวงกลม ↻) ที่ Extension

</details>
